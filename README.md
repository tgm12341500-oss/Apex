# Apex | Construction Company Website

A modern and responsive construction company website designed to present construction services, highlight company expertise, and showcase projects through a professional and user-friendly interface.

## Project Overview

Apex is a front-end web development project focused on creating a professional online presence for a construction and contracting company. It features a structured layout, clear navigation, and visually engaging sections that introduce the company and its services.

## Key Features

- Responsive website layout.
- Professional navigation bar.
- Hero section with construction-related visuals.
- Company introduction and About section.
- Services and features sections.
- Team presentation.
- Testimonials section.
- Clean and organized user interface.

## Technologies Used

- **HTML5** – Semantic structure and page content.
- **CSS3** – Custom styling and layout design.
- **Bootstrap 5** – Responsive layout and UI components.
- **JavaScript** – Bootstrap interactive components.

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
